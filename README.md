# 123kids storefront

A cheerful storefront for two digital coloring-book products for little artists. Product purchase links open Gumroad, which handles checkout and digital delivery.

## Products

- **My First Big Coloring Book** — Gumroad: https://taylorrk3.gumroad.com/l/wcwzu
- **Little Explorers Coloring Adventures** — Gumroad: https://taylorrk3.gumroad.com/l/harulh

Each product listing on Gumroad controls its price, included files, payment, and download delivery. This site displays the products and sends customers to the matching Gumroad listing.

## Preview locally

Open `index.html` in a browser, or run:

```sh
python3 -m http.server 8000
```

Visit `http://localhost:8000`.

## Deploy to Cloudflare Pages

Use `/` as the build output directory and leave the build command empty.
