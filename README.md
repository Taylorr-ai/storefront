# 123kids storefront

A playful, responsive storefront for coloring books and learning tools for children ages 0–6.

## Preview locally

Open `index.html` in a browser, or run:

```sh
python3 -m http.server 8000
```

Visit `http://localhost:8000`.

## Deploy to Cloudflare Pages

Use `/` as the build output directory and leave the build command empty.

## Customize

- Update products and prices in `app.js`.
- Update store copy and navigation in `index.html`.
- Update colors and layout in `styles.css`.
- Add a PayPal hosted button ID in `app.js` before accepting payments.
